# Rare Days Image Resizer

Convert JPEG and PNG images to WebP right in the browser. Nothing is uploaded — all processing happens on your device.

- Drop in any number of JPEG / PNG files
- **Compression** 0–100% in steps of 10
- **Scale** 10–100% in steps of 10
- See original vs. new file size, % saved, and dimensions for each image
- Download one at a time or all at once

**Use it:** https://joshofcourse.github.io/rare-days-image-resizer/
